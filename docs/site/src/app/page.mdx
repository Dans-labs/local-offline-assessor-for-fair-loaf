# Introduction

`fair-offline-assessor` is a Python library for assessing dataset metadata against
FAIR principles: Findable, Accessible, Interoperable and Reusable.

It was developed for [EOSC Data Commons](https://www.eosc-data-commons.eu/),
which builds services for research data discovery, access, sharing and reuse.
The library provides reusable offline assessment logic for the project's FAIR
assessment proxy and for other Python applications.

## How it works

Supply JSON-LD metadata and select an assessor. The library interprets the metadata,
runs the supported checks and returns an `AssessmentResult` with check outcomes,
metric scores and diagnostics.

Assessment runs locally. The library does not fetch datasets, resolve identifiers
or download remote JSON-LD contexts. This lets applications assess metadata before
publishing it or in environments without network access.

[F-UJI](/assessors/fuji) is the first supported assessor. It assesses individual
datasets. Its offline checks cannot establish whether a remote dataset or service
is actually reachable.
