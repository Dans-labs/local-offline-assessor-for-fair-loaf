# Introduction

`fair-offline-assessor` is a Python library for checking metadata: the information
that describes a dataset, such as its title, creator and licence. The checks
address FAIR principles: Findable, Accessible, Interoperable and Reusable.

An assessor defines what to check and how to assign points. The library currently
supports [F-UJI](/assessors/fuji).

## How it works

1. Choose an assessor and version.
2. Supply the dataset's metadata.
3. The assessor uses its own mappings to recognise fields, then applies its checks
   and scoring rules.
4. Read the check results, scores and messages. `raw` contains the assessor's
   original results from the run, unchanged.

The response uses the same field names regardless of assessor. This gives
applications one way to read results while keeping each assessor's check IDs
and scoring rules.

## What offline means

The library checks the information you supply. It does not download datasets,
open their links or contact external services. Checks that need information
unavailable offline are marked `indeterminate` and receive no score.

You can use it to check metadata before publishing it or in an application
without network access.
